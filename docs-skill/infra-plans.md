- Переписка с агентом — сделана в @horrordigestbot (раздел 5b), не в @frightclubai.

Не трогать: Letterboxd API (только по заявке, личным не дают), TikTok Research API (только академикам), чтение чужих TG-каналов (нужен пользовательский API — риск бана), Google Trends (официального API нет).
