# Рубрика «скоро» — карточка и шаблон текста

> Справочник скилла horror-news-digest. Правила работы — только в скилле; здесь — образец и параметры. Правится коммитом без карточки скилла.
> Читать перед любым постом «скоро» / «выходит в прокат на этой неделе».

Образец (утверждён Тимуром 3.11.2026): карточка `cards/2026-11-03-soon-week.jpg`
https://raw.githubusercontent.com/flyyyyy88645/frightclub-cards/d7d181242cd1b021f3e4f4cdaa454efbc5237152/cards/2026-11-03-soon-week.jpg

Два формата рубрики (решение Тимура 3.11.2026):
- **неделя** — «выходит в прокат на этой неделе», шаблон ниже;
- **следующий месяц** — хорроры следующего месяца, та же структура РФ / МИР; заголовок карточки и текста — под месяц, окно ресерча — весь месяц (раздел 1 скилла: релизы ±30 дней). Когда какой ставить, если Тимур не сказал, — спросить.

## Ресерч
- Окно — неделя (пн–вс) или следующий месяц. Источники: `tmdb_list` discover с датами недели (хоррор по умолчанию), kino.mail.ru/cinema/soon/ и kinoafisha.info/releases/ — для РФ; Bloody Disgusting, iHorror, сайты дистрибьюторов — для мира. Дата релиза всегда с регионом.
- Дата в РФ — по `tmdb_details` (release_dates_by_region.RU) или афише. Фестивальный показ (Horror Fest и т.п.) — не прокат.
- RT — только если уже есть (`movie_ratings`); нет — не пишем.
- Кассовые рекорды проверять по тексту статьи, а не по заголовку (3.11: заголовок «обогнал Конджиам», а в тексте — нет → написали «один из самых кассовых»).
- 4–6 фильмов. Популярный блокбастер можно, если это главный жанровый релиз недели.

## Шаблон текста (одно сообщение, ≤1024)

```
<b>выходит в прокат на этой неделе</b> 🫣

<b>РФ</b>

<b>Д.ММ — «русское название».</b> завязка одной фразой. один факт-крючок (сборы дома, фестиваль, режиссёр) 💀

<b>Д.ММ — «русское название».</b> завязка одной фразой

<b>МИР</b>

<b>Д.ММ — Original Title</b>, страна[, ограниченно]. завязка + факт 🗿

<b>Д.ММ — «русское название»</b>, страна (где ещё и когда). факт, у критиков пока NN% 🫠

что из этого ждёте больше всего?
```

- Сначала блок **РФ**, потом **МИР**; внутри — по дате. Пустой блок не ставить (нет релизов в РФ — только МИР, заголовок тот же).
- Название: официальное русское, если есть (`tmdb_details` ru); иначе оригинал без кавычек.
- Первый эмодзи в заголовке — не 👁👄👁 (Тимур поменял на 🫣).

Пример (3.11.2026, 871 знак):

```
<b>выходит в прокат на этой неделе</b> 🫣

<b>РФ</b>

<b>МИР</b>

<b>4.11 — The Last Temptation of Becky</b>, сша, ограниченно. третья «бекки»: теперь она агент цру под прикрытием в «волчьем логове», бывшей ставке гитлера. злодей — Нил Патрик Харрис 🗿

<b>5.11 — Ferine</b>, италия. коллекционерша после трагедии сама становится хищником. на Fantasia наградили оператора и композитора

что из этого ждёте больше всего?
```

## Карточка
Код — `cards.md`. Отличия рубрики:
- рубрика сверху справа: `скоро`;
- изображение — горизонтальный кадр одного фильма недели (лучше — из блока РФ), атмосферный, без надписей;
- заголовок: `выходит в прокат\nна этой неделе`, `title_size=110`, `split=50`;
- подпись под заголовком: `рф · мир · Д–Д месяца`;
- без рейтинга (`rt=None`);
- имя файла: `YYYY-MM-DD-soon-week.jpg`.

```python
card(img,'скоро','выходит в прокат\nна этой неделе','рф · мир · 3–9 ноября',None,
     title_size=110,split=50,
     img_box="top:120px;left:56px;width:968px;height:860px;transform:rotate(-.8deg)",
     pos="40% 50%")
```
