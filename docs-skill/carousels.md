# Карусели TikTok — генератор и параметры

> Справочник скилла horror-news-digest. Правила работы — только в скилле; здесь — данные и код. Правится коммитом без карточки скилла.
> Читать перед сборкой карусели (правила — скилл, раздел 7a). Что уже сделано — history/clips.md.

- Генератор: `tools/tt_carousel.py`; тексты — словарь STORIES (`tools/tt_stories.py`, `tools/tt_stories2.py`, `tools/tt_stories3.py` — примеры).
- Поля истории: `slug`, `img`, `cx` — центр кадра по горизонтали, `hook`, `sub`, `slides` [(крупно, текст)], `key` — индекс ключевого слайда с надрезом, `final_small`, `final_big`, `cover_bright` — поднять яркость тёмного кадра обложки, `hook_top` — отступ хука на обложке сверху, px (по умолчанию 1030).
- Кадр — через `tmdb_view_image` (файл в tool-results), шрифты — как в docs-skill/cards.md.
- Видео-слайдшоу из тех же слайдов: 3,6 с на слайд, кроссфейд 0,4 с, без звука.
- Безопасная зона текста: y 260–1500, справа отступ 150 px.
- Готовые слайды — `cards/tt-<тема>/`.
