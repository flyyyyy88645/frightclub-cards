# Конвейер нарезок TikTok

- `data.py` — описание роликов: CLIPS[k] = {p: [(start,end),…] в секундах фильма, flash: время пика или None, hook: (строка1, строка2), bgb: яркость фона (по умолч. −0.32; для светлых кадров −0.62), boost: (start,end) участок +14 дБ}; RU — перевод реплик по времени начала реплики в srt; CAPS — подписи.
- `gen.py` — оверлеи (хук + логотип) и ASS-субтитры. Пути к srt, логотипу (`docs/icon.png`) и шрифтам (`/home/claude/fontdl`) — поправить под сессию.
- `render.py <ключи через запятую|all> [номер аудиодорожки]` — рендер 1080×1920 по шаблону канала в `out/`.
Пример данных — «Заклинание» (2022), неделя 3.
