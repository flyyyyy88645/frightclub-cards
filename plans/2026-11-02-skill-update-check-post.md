# Дополнить скилл horror-news-digest: проверка постов (решение Тимура 2.11.2026)

Раздел 5, «Порядок», шаг 1 заменить на:

1. Ресерч → текст → карточка → **проверка** → **превью Тимуру в личку** (фото + полный текст ровно как в канале).
   **Проверка перед каждым превью** — чтобы Тимур смотрел только смысл и вкус, а не ловил мелочи:
   - **Формальное — скриптом:** `python3 tools/check_post.py post.txt --platform tg --rubric <рубрика> --image <ссылка на карточку> --facts-checked` (флаг — только если факты правда сверены, иначе в итоге «⚠️ факты не сверены»; для TikTok — `--platform tiktok`). ОШИБКА — исправить и прогнать заново; ВНИМАНИЕ — посмотреть самому. Новое замечание Тимура, которое можно выразить правилом, — дописывать в BANNED/WARN скрипта.
   - **Факты — заново инструментами, а не по памяти:** дата и регион, режиссёр, русское прокатное название (`tmdb_details`), RT (`movie_ratings` по tmdb_id). Бюджет/сборы — The Numbers. Расхождение — исправить. Пример 2.11: «с довоенных времён» в «Повороте не туда» → «со времён до Гражданской войны».
   - Под превью отдельным сообщением — строка итога скрипта и, если что-то исправил, одной строкой что. Проверка не заменяет «да» Тимура.

Раздел 2, про длину: «Длину считать скриптом `tools/check_post.py`».
Раздел 5, инфраструктура: воркер 1.10.0 (2.11.2026); `youtube_transcript` — текст видео из субтитров без ключа, длинное частями через offset; некоторые видео YouTube закрывает для Cloudflare проверкой «не бот» — тогда Тимур присылает «Показать текст видео». В `tools/` — `check_post.py`.
